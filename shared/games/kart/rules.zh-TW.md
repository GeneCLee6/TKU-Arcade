## 卡丁車是什麼？

瀏覽器裡的 3D 卡丁車，1 到 8 台車一起跑：朋友同一個房間、空位補電腦車，或兩者都有。每個人的瀏覽器開自己的車；房間負責算圈數、發道具、判定結果。甩尾加速的手感致敬 2000 年代的經典卡丁車遊戲；這裡的車、角色、賽道、道具與名稱都是我們自己的。

## 一場比賽

1. 房主選**賽道**、**圈數**（1 到 9）、**模式**與**賽制**，也可以在空位加電腦車。
2. 每個人在等待室選車與角色。六台車的極速、加速、轉向與重量各差一點。
3. 大家的賽道都載入後，鏡頭依序帶到每位車手，接著房間倒數：3、2、1、GO。最後半秒按前進會有起跑加速。
4. 最先跑完圈數的車獲勝。第一台完賽後，其他人還有 10 秒（畫面上倒數）；時間到還沒跑完的算未完賽，依跑到哪裡排名。之後前三名上頒獎台。

## 開車

- **甩尾**：轉向時按住甩尾鍵。甩尾會累積**加速條**；集滿變成一個噴射存量（最多兩個），按噴射鍵使用。一次只噴一個：噴射中再按不會有作用。
- **瞬間加速**：真的甩出去（車尾滑出來、甩了一小段）就賺到一次短暫的加速；點一下就放的不算。放開甩尾後，在車還在滑、或剛回正的時候重新按一次前進。甩尾時車會滑、會掉一點速度，所以直線上硬甩並不划算。
- **復位**：把車放回上一個檢查點的路上。

「卡丁車」頁面的操作面板列出鍵盤、手把與觸控按鈕，也可以改鍵。比賽中按 Esc（手把 Start、或左上的暫停鍵）打開選單：設定音量、畫質、特效與開場動畫；一個人玩時比賽會暫停，多人房比賽照跑。

**駕訓班**：「卡丁車」頁面的選單裡有十一堂短課，一堂一招，從跑完第一圈到甩尾起跳：甩尾、瞬間加速、完美時機、連段、N2O、完美起跑、甩尾起跳、落地時機噴、穿縫，最後一堂綜合考驗。每一課都顯示你自己的按鍵，失敗時告訴你差在哪，可以重來或跳過；過關給 1–3 顆星。比賽中，還沒用過的技巧會給一次簡短提示（操作面板可以關）。

**挑戰**：選單裡的「挑戰」有兩種玩法。**任務**分四章（入門、技術、高手、魔王），每關一張賽道一個條件：不撞牆跑完、連段達標、甩尾起跳幾次、穿過牆上的每一道門、走遍每條岔路、每圈都飛上每座高台、不用 N2O 進前三、在海霧裡完賽、騎摩托車、淘汰賽（每圈最後過線的出局）、一對一贏過專家電腦車等；過關給 1–3 顆星，前一章過四關下一章才打開。**獎牌牆**是每張賽道的三圈計時賽，跑贏目標時間拿銅、銀、金牌，拿到金牌還會出現一面隱藏的獎牌；可以選擇和目標時間的幽靈車一起跑。

## 進階技巧

有些賽道（**碼頭倉庫**、**山城坡巷**、**高架廠區**、**防波堤屋頂**）要背圖：一眼看到的那條路是遠路，近路要會下面其中一招才過得去。有的近路是一條自己的路，也就是**岔路**：離開主路、另走一段、再接回來；檢查點一樣算，在岔路上復位就回到岔路上。

- **甩尾起跳**：在跳台**之前**就開始甩尾，甩尾鍵按住不放。車會照滑行的方向飛出去，不是照路的方向；空中打方向可以把車頭甩得比平常多很多；落地時已經在甩尾裡、馬上轉彎，還補一大段加速條，瞬間加速也已經賺到（放開甩尾、重按前進）。直直衝上去的車落地也是直的，落地後才開始轉：跳台後面緊接髮夾彎的地方，那就是撞上對面的牆。
- **落地時機噴**：飛過跳台時在空中先放開前進，車子碰地的那一下（前後十分之一秒內）再按：落地的加速比一路按著前進落地的長一半。只算直直飛、車頭對正的落地；甩尾起跳落地照舊。
- **貼牆滑行**：用很淺的角度（大約 12° 以內）擦到牆，車會沿著牆滑，只掉一點速，連段也不斷；角度一大就是撞牆。貼牆有時能抄近一點，但一路擦著牆比好好走線慢，而且甩尾中碰到牆，那一次出彎的加速條獎勵就沒了。
- **坡頂收油**：不會甩尾起跳的話，跳台後面接彎只有一個辦法，上跳台前先鬆開前進。起跳越快飛得越遠，而車在空中不能煞車也不能轉。
- **飛越矮欄**：黃色的矮欄只能用飛的過去。矮欄後面的車道要從前一個跳台斜著起跳才進得去，也就是朝那條車道甩尾起跳。
- **穿縫**：高牆（倉庫、貨櫃列、院牆）上有只容一台車的缺口，幾個缺口排成一直線，但要開到線上才看得到。提早對準、不要甩、直直穿過去；偏一公尺就是正面撞牆。每個缺口後面有一條加速帶。
- **盲彎切入**：有的岔路入口只開一下，藏在牆後或坡頂後面。看到之前就要先靠到那一邊、開始轉；慢了就撞上牆角。
- **高台捷徑**：有些跳台旁邊是一座比路高的平台（貨櫃頂、廠房屋頂、夜市屋頂、防波堤頂），正面是一道牆，頂上一排琥珀燈。只有起跳**夠快**又**斜著朝平台飛**的車飛得上去：上坡時噴一個 N2O、前一個彎甩出瞬間加速、或踩過坡前的加速帶都能幫忙，極速高的車比較容易，上坡時輕的車掉速比較少。速度不夠就撞上正面的牆、落回主路（損失時間，不會被重置）；上去後的平台窄，中間可能有一道縫（掉進去要爬出來），盡頭直接跳回主路。主路則要繞過整棟建築，遠很多。**碼頭倉庫**、**高架廠區**、**淡海夜城**各有一座，**防波堤屋頂**有三座。

**專家**級的電腦車會走這些近路；簡單、普通、困難三級一律走遠路。困難與專家都會完美時機的瞬間加速和連段。在「卡丁車」頁面網址加 `?autopilot=master` 可以看每條近路都走的駕駛；`?autopilot=expert` 是很會開、但不認得這張圖的駕駛。

## 模式

- **道具賽**：路上有道具箱。開過去就抽一個道具，依名次抽：越後面越強。按道具鍵使用，一次只能拿一個。
- **競速賽**：沒有道具，只比駕駛。

十四種道具。「前一台」是指你正前面那台；團隊賽裡，會傷人的道具都不會打到隊友。

| 道具 | 效果 | 誰比較容易拿到 |
| --- | --- | --- |
| 順風 | 加速 | 每個名次 |
| 泡泡罩 | 擋下一次會傷人的道具或投射物，然後破掉 | 前段 |
| 牽罟繩 | 把你拉向前一台 | 中段、後段 |
| 東北季風 | 前面所有人變慢幾秒；泡泡罩擋得住 | 後段 |
| 洗牌 | 和同一圈的前一台交換位置；泡泡罩擋得住 | 中段、後段 |
| 浪花 | 往正前方丟，撞牆就停 | 中段、後段 |
| 雷陣雨 | 追著前一台，飄到就打 | 後段 |
| 泥灘 | 丟在車後，誰開進去都會打轉（過一下子你自己也會） | 前段 |
| 回浪板 | 8 秒內，下一個會打中你的投射物會彈回給丟的人（對方有泡泡罩就擋掉）。對東北季風、洗牌、靜電沒用。和泡泡罩同時開著時先用回浪板 | 前段 |
| 海霧 | 在前一台的正前方路面出現一團霧，停留 7 秒。開進去畫面會起霧約一秒半、車速被拖慢一點。不算攻擊：泡泡罩和回浪板都擋不住，放霧的人自己不受影響 | 中段、後段 |
| 打水漂 | 沿著賽道跳到下一個檢查點，落地時小加速；不會跳過終點線 | 後段 |
| 靜電 | 全場第一台（團隊賽是對方隊伍最前面那台）3.5 秒內放不出噴射，正在噴的也會斷掉。泡泡罩擋得住。第一名拿不到 | 中段、後段 |
| 加油旗 | 只在團隊賽：你和每個還在跑的隊友都小加速 | 每個名次 |
| 假箱子 | 長得像道具箱（核心是暗紅色、轉得比較慢）；丟在車後，誰開進去都會打轉。泡泡罩擋得住 | 前段 |

被打中的車會打轉、慢下來大約一秒。會打到前面的道具，第一名一律拿不到。

**道具型車款**（車庫裡的「拾貝系」）把一部分點數花在道具上、不是花在駕駛上：鵜鶘的泡泡罩可以擋兩次；水獺比較容易拿到強道具、自己的道具效果久四分之一；鸕鶿抽道具箱運氣最好、泡泡罩也能擋兩次。在競速賽裡它們就是稍微慢一點。這些都由房間依你選的車裁定。

## 團隊賽

把**賽制**設成**團隊賽**，車子分成**夕照隊**與**河口隊**兩隊比賽。道具賽與競速賽都可以是團隊賽。

- **分隊**：在等待室每個人選夕照隊或河口隊。沒選的人開賽時自動排到人少的那一隊。房主可以幫任何人換隊（電腦車也可以），按**自動平衡**會清掉所有人的選擇、重新平均分配。常見的是 2 對 2、3 對 3、4 對 4。
- **加速條是自己集自己的**：和個人賽一樣，每個人甩尾集自己的加速條，集滿得到一個自己的噴射存量（最多兩個）。平常的噴射是**紅色**的。
- **同舟條與漲潮**：每隊另外共用一條藍色的團隊加速條「同舟條」，顯示在你自己的加速條旁邊。只有甩尾會幫它累積，隊上任何人甩尾都算；大約是全隊每個人都集滿自己的加速條兩次的量，人多的隊不會比較快。它滿的那一刻，隊上每台車**手上已經有的**噴射存量全部變成**藍色**的**漲潮**；手上沒有存量的人這次就沒有。漲潮噴藍色的火，時間大約是紅色的一倍半，極速也更高。存量格上藍色排在前面，按噴射鍵先用藍色的。一次只噴一個。藍色是這種噴射的顏色，和隊伍無關：兩隊的都是藍色。
- **計分**：名次得分 **10、8、6、5、4、3、2、1**；未完賽 0 分。每隊取成績最好的幾台相加，台數等於人少那一隊的人數，所以 3 對 2 也公平。總分高的隊獲勝；同分時，第一名所屬的那一隊贏。

結果畫面會顯示哪一隊獲勝、兩隊總分，以及每台車的隊伍、時間與得分。

## 電腦車

房主可以在空位加電腦車，有四種難度：簡單、普通、困難、專家。專家會本頁所有的技巧（完美時機、連段、甩尾起跳、坡頂收油、穿縫、背圖近路），但和大家一樣受同一台車的極速限制，不會作弊加速。電腦車由房主的瀏覽器代跑，所以房主離開時它們也會退賽；房主只是短暫斷線、15 秒內在同一個頁面連回來，電腦車會繼續跑。在「卡丁車」頁面也可以一個人對戰電腦：單場、和電腦隊友組隊的團隊賽，或連跑幾張賽道的大獎賽。

## 觀戰

比賽中才進房間的人、或已經退賽的人，可以即時觀戰並切換要跟的車。比賽結束後，每個瀏覽器可以重播自己看到的過程。
