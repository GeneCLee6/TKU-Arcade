## 真假朗讀是什麼？

一款比誰比較會唬人的派對遊戲。每回合大家看到同一個冷門的名詞，只有一個人拿到真正的解釋，其他人要當場編一段聽起來像真的；裁判聽完所有人的朗讀，要找出說真話的那一位。朗讀面對面或開語音，網站負責發卡、計時、投票與計分。

「一人照念真解釋、其他人瞎掰、裁判找出老實人」的玩法來自台灣桌遊《9upper 瞎掰王》（TIME2PLAY GAMES）；這裡的題目、文字、畫面、暗樁、吐槽貼與計分都是我們自己的。

## 角色

- **裁判**：照座位輪流當，每人一局當一次（房主可以設成兩次）。大家都知道誰是裁判。裁判只看得到名詞。
- **老實人**：從其他人裡秘密抽一位，拿到**真正的解釋**，輪到他時照念。
- **暗樁**：4 人以上時，再從其他人裡秘密抽一位。暗樁也要瞎掰，另外拿到 **3 個任務詞**，要把它們都塞進自己的朗讀裡。有沒有塞進去網站不判斷，靠大家聽。
- **瞎掰人**：剩下的人。看得到名詞與一個小提示，要編一段像真的解釋。

每個人只知道自己的角色。

## 一回合

1. **看卡**：每人看自己的卡，15 秒，或裁判按「開始朗讀」。怕旁邊的人偷看，可以先把卡蓋住。
2. **朗讀**：除了裁判以外的人照網站排的隨機順序，一人念一段，每人 60 秒（房主可以改）。念的人自己或裁判可以提早結束。
3. **投票**：60 秒。裁判投一票選出老實人，只能投一次。其他每個人（包括老實人和暗樁）可以貼 **1 張吐槽貼**給覺得講得最爛的人，不能貼自己，也可以不貼；裁判不貼。揭曉前看得到誰已經決定，看不到投給誰、貼給誰。
4. **揭曉**：裁判投完、而且大家都決定好就揭曉（時間到也揭曉，沒決定的當作不貼）。老實人、暗樁、任務詞、真正的解釋、裁判的票、每張吐槽貼全部公開，這回合計分。
5. 裁判按下一回合，換下一個座位當裁判。

## 計分

| 情況 | 分數 |
| --- | --- |
| 裁判投中老實人 | 裁判 +2、老實人 +2 |
| 裁判投到瞎掰人或暗樁 | 被投的人 +3 |
| 吐槽貼貼到老實人 | 貼的人 −1 |
| 吐槽貼貼到暗樁 | 貼的人 +2 |
| 吐槽貼貼到一般瞎掰人 | 0 |
| 這回合沒有人貼到暗樁 | 暗樁 +2 |
| 裁判沒投（時間到或離線） | 投票這項沒有人得分，吐槽貼照算 |

每個人都當過裁判後遊戲結束，分數最高的人獲勝，同分並列。

## 規則選項

由房主在等待室設定。

- **每人當兩次裁判**：回合數變成人數的兩倍。
- **每人朗讀秒數**：20 到 180 秒，預設 60。
- **有暗樁（4 人以上）**：關掉就沒有暗樁，也沒有任務詞。
- **瞎掰的人看得到提示**：關掉的話，瞎掰人和暗樁只看得到名詞。
- **倒數計時**：關掉就沒有看卡、朗讀、投票的倒數，全靠按鈕往下走。

## 有人離線

- 裁判在看卡時離線，房主可以跳過，直接開始朗讀。
- 正在朗讀的人離線，跳到下一位。
- 投票時沒決定的人離線，當作不貼；裁判離線，他的票不算。
- 揭曉時裁判離線，房主可以替他開下一回合。

## 聊天

看卡、朗讀、投票時聊天室關閉（打一句「我是老實人」就沒得玩了），揭曉時打開。

## 題目

名詞都是真的存在、但多數人沒聽過的詞，解釋是我們用自己的話寫的。題目目前只有中文。

## 人數

3–9 人。一局大約 30 分鐘。
