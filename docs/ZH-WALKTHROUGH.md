## 怎麼走

1. **程式走**：`npm run dev`，另開終端機 `npx playwright test zh-walkthrough`（`e2e/zh-walkthrough.spec.ts`）。手機與桌機各走一次，每個畫面讀可見文字、`aria-label`、`title`、`placeholder`、`alt`、SVG 的 `<title>`、`<option>`，並確認 `<html lang="zh-TW">`。新畫面要加進去。
2. **人讀**：`src/i18n/zh-TW.ts`、遊戲的 `i18n.ts`、規則頁 markdown 從頭讀過：台灣用語、術語表（`DESIGN.md` §5）、同一件事同一種說法。

可以留英文的只有：`TKU Arcade`、語言切換的 `EN`、`QR code`、按鍵名 `Enter`、`Shift`，以及玩家自己取的暱稱與網址。
