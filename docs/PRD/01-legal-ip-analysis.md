# 版權與智慧財產分析

> 這份回答擁有者的問題：「我沒有要營利，只做給自己跟朋友玩，這樣是不是比較沒有版權問題？」
> 結論先講：**非營利會降低被告與賠償的風險，但不會讓「重製」變成合法。** 真正的保護傘不是「不賺錢」，而是「不抄受保護的表達」。照 §4 的原則做，這個專案可以合法地存在，而且不用躲。
>
> 這不是法律意見書；寫這份是依 `PLANNING-METHOD.md` §3 第 1 條（法律風險、錯了很貴）開的 feature 文件。真的被通知或想對外發布前，找律師。

## 1. 法律上的基本框架（台灣）

### 1.1 著作權只保護「表達」，不保護「玩法」

著作權法第 10 條之 1：「依本法取得之著作權，其保護僅及於該著作之表達，而不及於其所表達之思想、程序、製程、系統、操作方法、概念、原理、發現。」

遊戲的**規則、機制、操作方法**（甩尾累積加速條、籌碼暗示手牌順序、用一句話表達祕密數字的大小、一人照念其他人瞎掰）是「系統」與「操作方法」，**不受著作權保護**。這是全世界的通則（美國是 idea/expression dichotomy，17 U.S.C. §102(b)），桌遊界的例子是任何人都可以做「跟 Monopoly 規則一樣」的遊戲，只要不叫 Monopoly、不用它的圖。

受保護的是**表達**：

| 類別 | 著作類型 | 例子 |
| --- | --- | --- |
| 美術 | 美術著作 | 角色設計、車款造型、卡牌插畫、圖版、介面圖像、Logo |
| 文字 | 語文著作 | 題目卡上的名詞解釋段落、說明書、劇情文字、角色介紹 |
| 音樂與音效 | 音樂著作、錄音著作 | 背景音樂、引擎聲、勝利音效 |
| 程式碼 | 電腦程式著作 | 原作的任何程式碼、反編譯出來的資料 |
| 3D 資料 | 美術／電腦程式著作 | 從遊戲檔案擷取的模型、貼圖、賽道資料 |
| 角色 | 美術＋語文的組合 | 皮蛋、Dao、Bazzi 這類有具體造型與名字的角色 |

### 1.2 商標另外算

「跑跑卡丁車」「KartRider」「紙牌幫」「The Gang」「瞎掰王」「9upper」「Wavelength」「腦洞量表」「ito」都是（或可能是）註冊商標或有識別性的名稱。**把它們拿來當自己遊戲的名字**，不管有沒有營利，都是商標問題（混淆誤認）；在規則頁寫「玩法致敬 Wavelength」這種**描述性使用**則通常沒問題。

### 1.3 「非營利」在法條裡的位置

- 著作權法第 65 條「合理使用」的判斷因素之一是「利用之目的及性質，包括係為商業目的或非營利教育目的」。**非營利是加分，不是免死金牌**；另外三個因素是著作性質、利用的質量比例、對市場的影響。把一整款遊戲的美術與角色重做出來，「質量比例」就是 100%，合理使用幾乎不會成立。
- 第 51 條「供個人或家庭為非營利之目的」的重製，前提是「在合理範圍內」且「利用圖書館及非供公眾使用之機器」——**放在網路上給朋友點連結，就是「公開傳輸」（第 3 條第 1 項第 10 款），不在第 51 條範圍。**
- 台灣的著作權侵害有刑事責任（第 91 條起），但多數是**告訴乃論**：權利人不告就沒事。這就是「非營利」在實務上有用的地方：**被告的機率低**，不是「不違法」。

### 1.4 權利人真的會管同人嗎

- 任天堂對非營利同人遊戲（AM2R、Super Mario 64 HD、Mario Royale 等）一律發 DMCA 下架（[Engadget](https://www.engadget.com/2016/09/05/nintendo-issues-dmca-takedown-for-hundreds-of-fan-games/)、[PC Gamer](https://www.pcgamer.com/nintendo-issues-dmca-notice-against-that-really-good-metroid-ii-fan-remake)）。這些案子全部**沒有營利**，還是被下架；但也**沒有一件打到法院判賠**。
- Nexon（跑跑卡丁車的權利人）對「像」的作品態度積極：對 Ironmace 的《Dark and Darker》提告（那是前員工帶走資料的案子，不是單純「玩法像」），也多次處理私服。台服代理遊戲橘子的合約已到期（[TVBS](https://cars.tvbs.com.tw/car-news/83527)），台灣這邊目前沒有營運方。
- 桌遊出版社對「玩法一樣但名稱美術不同」的遊戲基本上無法可管，這是桌遊業的常態（例如 Wavelength 本身就有很多類似的「光譜猜題」app）。但**題目卡的文字**是語文著作，逐字搬過來就是侵權。

## 2. 對這個專案五款遊戲的逐一判斷

### 2.1 陞官圖

- 名稱：2026-11-09 擁有者拍板中文名用「陞官圖」（傳統上也寫作「升官圖」，兩種寫法都是這款民間遊戲本身的名稱，不是任何出版社的商標）；英文 Promotion 不變。
- 清代以來的民間遊戲，作者不詳、年代久遠，**規則與傳統圖版都是公有領域**。
- 不能抄的：現代出版社重新繪製的圖版美術、他們重寫的規則說明文字。
- 可以用的：歷史官職名稱與品級（史實不受保護）、傳統的「德才功贓」骰子機制。
- **風險：極低。** 自己畫圖版、自己寫說明即可。
- **完整版的抉擇與新增制度（C8，2026-11-12）**：擁有者給了一張傳統風格完整版圖版的截圖（看起來來自那個線上版）。**這張截圖只被當成「我們的圖版還缺哪些清代制度與名目」的清單**（宗人府、內務府、內廷、中書科、欽天監、太醫院、鑾儀衛、五城兵馬司、倉場、學院、鹽院、河院、漕院、京察、大計、大考、軍功、處分、曠典、各館謄錄、兼銜、品級考）：這些是公有領域的史實名稱。**沒有照截圖畫、沒有抄它的格子排法、去向、數字或文字，也沒有打開那個網站**。新增的 55 格的官名與品級依公有領域的清代官制，去向、考績結果表、捐納價錢的細節是本專案依傳統大意重建或自己設計的，在 e3 epic「C8：第二套規則與圖版」逐條標〔傳統〕〔重建〕〔設計〕〔擁有者定〕〔傳統變體〕。協調者轉述的傳統規則（謄錄、捐納、公差、大賀、出局）是以自己的話寫的大意，規則頁兩種語言都是自己的文字。
- **完整版的來源（C6，2026-11-12）**：擁有者提到網路上有一個線上版。**我們沒有打開、讀取或抄錄那個網站，也沒有參考任何現代版本的圖版、表格或說明文字**。完整版的 182 格是 AI 協作者依公有領域的清代官制知識（官名、品級、部院寺監、科舉功名、旗民之分）自行整理的；格子之間的去向、骰子組合的細節、銀兩數目是本專案依傳統玩法大意重建或自己設計的，在 e3 epic「完整版規則細節」逐條標明哪些是傳統、哪些是重建。規則頁兩份（`shared/games/promotion/rulesFull.{en,zh-TW}.md`）是自己的文字，測試擋網址與其他遊戲名稱。旗籍／民籍是歷史制度，規則頁寫明是「示意清代的旗民之分」。

### 2.2 紙牌幫（The Gang）風格的合作撲克

- 原作：The Gang，設計 John Cooper／Kory Heath，台灣由栢龍代理（[卡牌屋](https://bghut.com/goods-12604.html)、[栢龍](https://broadwaytw.shoplineapp.com/products/the-gang)）。玩法是德州撲克牌型＋不能說話、用籌碼暗示手牌大小的順序。
- 不受保護：撲克牌型比較（更是公有領域）、籌碼暗示的機制、關卡制。
- 不能抄：名稱「紙牌幫／The Gang」、盜匪主題的美術、籌碼圖樣、說明書文字。
- 建議：換主題（例如「潛水隊」「登山隊」），籌碼改成自己的圖示；規則用自己的話寫。
- **風險：低。**

### 2.3 光譜猜題（暫名 Spectrum）：祕密數字猜大小

> 2026-11-09 擁有者改了規則（`e5-spectrum-guess.md`）：舊版參考 Wavelength 腦洞量表（兩隊、藏起來的目標扇形、轉刻度、猜左右），**已整套拿掉**。新玩法比較接近下面這款。

- 原作：ito，日本 Arclight（アークライト）出版的卡牌遊戲。玩法：每人拿到一張祕密數字，依題目用一句話表達自己數字的大小，大家一起由小排到大（合作）。
- 我們的版本：數字 1–10、一位猜題者輪替、其他人各給一個回答、猜題者猜誰最大誰最小（或全排序）、個人計分。和原作的差別在人數結構與計分，但**核心機制相近，所以比照原作處理**。
- 不受保護：「祕密數字＋依題目表達大小＋排序或猜大小」的機制、計分方式。
- 不能抄：名稱「ito」（我們的暫名「光譜」，正式名稱在總 PRD Q3；也不用 Wavelength、腦洞量表）、卡牌與包裝美術、說明書文字、**題目卡上的題目文字**（逐題是語文著作，整組的選擇與編排也可能構成編輯著作）。
- 建議：
  - 題庫**全部自寫**（≥ 300 題，草稿在 `docs/content/spectrum-topics.zh-TW.csv`），擁有者逐題審過才上線；寫題時不參考原作的題目卡。「好吃—難吃」這種通用的兩端是一般概念，可以用，但不要整批照某個出版品的題目寫。
  - 規則頁用自己的話寫；要提原作只用一句描述。
  - 畫面用自己的視覺（數線、回答卡），不模仿原作的卡牌樣式。
- **風險：低（題庫自寫、名稱與美術原創的前提下）。**

### 2.4 瞎掰王（9upper）風格的真假朗讀

- 原作：9upper 瞎掰王，TIME2PLAY GAMES，2021 年台灣原創（[BoardGameMatcher](https://boardgamematcher.com/game/9upper)）。玩法：每回合一位裁判、一位老實人照念卡片上的解釋，其他人瞎掰；裁判找老實人。
- 不受保護：角色分派機制、朗讀與投票流程。
- 不能抄：名稱「瞎掰王／9upper」、**題目卡的名詞與解釋段落**（這是整款遊戲最核心的語文著作）、「公三小」等獎懲牌的文字與美術。
- 建議：題庫全部自寫或 AI 生成後人工審核；解釋段落可以引用公有領域或自己改寫的百科知識（事實不受保護，但百科條文的文字受保護，要改寫）。
- 另外注意：原作是**台灣的小出版社**，同在台灣、容易被看到；就算法律上站得住，也要尊重。建議在規則頁註明「玩法致敬 9upper 瞎掰王（TIME2PLAY GAMES），題目與美術為本站原創」——這是描述性使用，也是禮貌。
- **風險：低（題庫自寫）；若抄題目則高。**

### 2.5 跑跑卡丁車風格的卡丁車

- 原作：Crazyracing KartRider，Nexon；台灣由遊戲橘子代理，台服 2023-01-31 關閉；續作 KartRider: Drift 2025 年宣布停服（[TechBang](https://www.techbang.com/posts/126139-kartrider-drift-nitro-studio-bankruptcy)）。
- 不受保護：**甩尾累積加速條、放開噴射的操作手感**、道具賽的概念、時間賽、幽靈車、卡丁車競速本身（Mario Kart 以降整個類型都是這樣）。
- 不能抄（這些全部是 Nexon 的）：名稱與商標、角色（皮蛋／Dao、Bazzi、Marid、Uni 等）與其造型、車款名稱（舒適 SR、黑旋風等）與造型、賽道（森林、冰河、沙漠、城鎮…的具體設計與地形）、音樂與音效、介面圖像、任何從遊戲檔案擷取的模型與貼圖、私服程式碼。
- 「玩到後面的車」這個願望要重新理解：**原作的車款不能出現**，能做的是「自己設計的車款，解鎖節奏像原作」。
- 建議：
  - 產品名稱與遊戲名稱原創（暫名 Kart，拍板時換）；公開文字不出現「跑跑卡丁車」「KartRider」當名稱，規則頁可以寫「致敬 2000 年代的經典卡丁車手感」。
  - 美術走**低多邊形卡通**，角色與車款完全原創（可以用社團的梗：橋牌花色、淡水河、克難坡）。
  - 賽道原創主題；不重建原作任何一張賽道的佈局。
  - 音效自己錄或 CC0。
  - 不上 Steam／itch.io／遊戲平台，不投稿到遊戲社群，不做「復刻跑跑」的宣傳；只在朋友圈分享連結。
  - 若收到權利人通知，E12 的功能旗標可以一鍵下架卡丁車，其他桌遊不受影響。
- **風險：中（因為權利人積極、而且「像」是刻意的）；照上面做則法律上站得住，實務上也不太會被注意到。**

### 2.6 誰的詞不一樣（「誰是臥底」玩法，2026-11-14 加）

- 原作：「誰是臥底」是華語圈民間流傳的派對遊戲（電視綜藝節目也用過），沒有單一出版社或題卡。
- 不受保護：多數人一個詞、少數人一個相近的詞、輪流描述找人的玩法。
- 不能做：拿電視節目或網路上整理好的詞組清單直接用；「誰是臥底」當自己的遊戲名稱（雖然是通稱，§4-2 仍要原創名稱）。
- 做法：暫名「誰的詞不一樣／Odd Word Out」，詞組全部自寫，規則頁用一句話描述它像「誰是臥底」。
- **風險：很低。**

### 2.7 滬尾商行（Splendor 玩法，2026-11-14 加）

- 原作：Splendor（中文版名「璀璨寶石」），Marc André 設計、Space Cowboys 出版的拿籌碼買牌、牌給永久折扣的引擎構築遊戲。
- 不受保護：拿三種不同籌碼／一堆四個以上可拿兩個同色、保留牌拿萬用籌碼、牌給永久折扣、三層牌、達到條件自動來訪的貴族、15 分結束這一輪等玩法與數字結構。
- 不能做：遊戲名稱、文藝復興寶石商人主題、寶石與貴族的美術、**原作的卡表**（每張牌的價錢與分數、貴族的條件）、規則書文字。
- 做法：暫名「滬尾商行／Tamsui Traders」，主題換成茶葉年代的淡水河港（茶葉、樟腦、藍靛、蔗糖、胡椒、金），牌與貴客全部自己設計（`docs/content/traders-cards.csv`、`traders-patrons.csv`，價錢曲線類似但沒有照抄任何一張），規則頁用一句話描述它玩起來像 Splendor。
- **風險：低。** 唯一要注意的是卡表：之後調整平衡時也不要拿原作卡表來對。

## 4. 這個專案的 IP 原則（寫進 CLAUDE.md 的版本）

1. **玩法可學，表達不抄。** 規則、機制、手感可以參考；名稱、角色、美術、音樂、文字、程式、資料檔一律原創或授權可用。
2. **名稱全部原創**，不與原作相同或近似；提到原作只在規則頁用描述性的一句話。
3. **題庫自寫**；AI 生成要人工審核，並檢查不是原作的題目改寫。
4. **資產一律登記**（`docs/ASSETS.md`），CI 擋漏登記。
5. **不對外宣傳、不上平台**；連結只給朋友。
6. **接到通知就下架**，不爭辯；功能旗標要能分遊戲關閉。
7. 上線任何一款新遊戲前跑一次 **IP 檢查清單**（E12 AC-12.8）。
8. **不抄表達的原作**，除了 CLAUDE.md 規則 1 列的五款，路線圖外的新遊戲另外加上：Splendor（璀璨寶石，Space Cowboys，2026-11-14，見 §2.7）。

## 5. 回答擁有者的三個問題

1. **「非營利是不是比較沒有版權問題？」** 比較不會被告，但不等於合法。合法來自「不抄表達」，不來自「不賺錢」。照 §4 做就兩者兼顧。
2. **「做得出來嗎？」** 桌遊：可以，技術和牌桌一樣。卡丁車：可以，瀏覽器裡的 three.js 做街機式卡丁車是成熟題目（開源範例如 MarioKart.js 用 React Three Fiber 重現了類似手感），多人同步用 Durable Object 與牌桌同一套；最大的成本是**3D 內容**（賽道、車、角色）與**手感調校**，不是技術可行性。總 PRD 把它排在 M2–M3 並先做 spike，就是為了這個。
3. **「能幫我從 PRD 開始設計嗎？」** 這個資料夾就是：`00-prd.md` 總 PRD、本檔、`e1`～`e12` epic、`../ROADMAP.md` 批次、`../NEXT.md` 交接。
