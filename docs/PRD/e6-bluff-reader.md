## 背景

致敬《9upper 瞎掰王》（TIME2PLAY GAMES，台灣原創）：每回合一位裁判、一位老實人、其餘瞎掰人；大家看到同一個名詞，只有老實人拿到真正的解釋並照念，瞎掰人要即興編一段像真的；裁判找出老實人。這款的靈魂是**題目卡的文字**，那正是原作受保護的核心，所以題庫一定自寫（`01-legal-ip-analysis.md` §2.4）。網站只負責發題、分派角色、計時、投票、計分；朗讀本身面對面或開語音。

## 目標

- M1：3–9 人完整一局、題庫 ≥ 100 題（**只做繁中**，擁有者 2026-11-13）、角色分派與回合流程、裁判投票與計分、題目管理與 AI 草稿。

## 非目標

- 站內語音（總 PRD Q6；用 LongTalk 或面對面）。
- 用語音辨識自動判斷誰在念（不做）。

## 需求

- **規則（自己的話寫）**：每回合輪一人當裁判（公開）；系統從其他人中秘密選一位老實人；所有人看到名詞；老實人看到完整解釋段落；瞎掰人只看到名詞與一個小提示（類別、字數）；依系統給的順序輪流「朗讀」60 秒（可調）；裁判投票選老實人；裁判猜對：裁判與老實人各得 2 分；猜錯：被誤指的瞎掰人得 3 分；輪完設定回合數後比分。
- **題庫**：名詞（zh-TW、en）、解釋段落（雙語，各 60–120 字）、類別、難度、提示；來源：自寫（改寫公有領域知識、自己的話）、朋友投稿、AI 草稿審核；存 D1 `prompts`，`game='bluff'`。**不轉載原作任何一題**，也不逐字搬百科。
- **回合流程與計時**：準備（角色私下顯示，10 秒）→ 朗讀順序逐人倒數（每人 60 秒，可提前結束）→ 裁判投票（60 秒）→ 揭曉與計分（含「老實人是誰」動畫）。
- **view**：裁判看名詞與投票介面；老實人看名詞＋解釋；瞎掰人看名詞＋提示；旁觀者看名詞，揭曉後看到全部。
- **規則選項**：回合數、朗讀秒數、難度、類別、是否顯示字數提示。
- **題目管理頁**：與 E5 共用元件（`e5-t06`），差別只在欄位。

## 設計方向

- action：`startReading`、`doneReading`（朗讀者本人或裁判）、`vote(seat)`、`next`；`timers` 驅動各階段。
- 手機優先：這款多半是面對面、每人看自己的手機，畫面要大字、單手。
- 「提示」給瞎掰人是為了讓瞎掰更像；提示由題庫欄位提供，不是自動生成。

## 2026-11-13 擁有者定案的規則（I1 照這個寫，程式在 `shared/games/bluff/rules.ts`）

擁有者確認上面的基本規則，並加兩樣東西。名稱避開原作：原作的書名是「瞎掰王」、獎懲牌叫「公三小」（`01-legal-ip-analysis.md` §2.4），擁有者提的「瞎掰帝」「公蝦毀」太接近，改用**暗樁**與**吐槽貼**（擁有者 2026-11-13 選定）。

- **角色**：裁判（公開，照座位輪替，一局每人一次，選項兩次）；其他人裡秘密抽一位**老實人**（拿到真正的解釋照念）；**4 人以上**再從其餘人裡秘密抽一位**暗樁**（選項可關）；剩下的是瞎掰人。暗樁也要瞎掰，另外拿到 **3 個任務詞**（`bluff-words.zh-TW.csv` 隨機），要在瞎掰時把詞塞進去。有沒有塞進去不自動判斷，靠大家聽：沒塞好就容易被貼。
- **流程**：準備（每人看自己的卡，15 秒，或裁判按「開始朗讀」）→ 朗讀（除了裁判以外的人，隨機順序，一人一段，選項秒數預設 60；本人或裁判可以提早結束）→ 投票（60 秒）→ 揭曉（裁判按下一回合）。
- **投票與吐槽貼**：裁判投一票選老實人（只能投一次）。其他每個人（含老實人與暗樁）每回合最多貼 **1 張吐槽貼**，貼給覺得講得最爛的人，不能貼自己，可以不貼；裁判不貼。裁判投完而且每個人都決定好（貼或不貼）就揭曉；時間到也揭曉，沒決定的當作不貼。揭曉前誰投誰、誰貼誰都看不到，只看得到誰已經決定。
- **計分**（擁有者 2026-11-13 同意的建議）：

  | 情況 | 分數 |
  | --- | --- |
  | 裁判投中老實人 | 裁判 +2、老實人 +2 |
  | 裁判投到瞎掰人或暗樁 | 那個人 +3 |
  | 吐槽貼貼到老實人 | 貼的人 −1 |
  | 吐槽貼貼到暗樁 | 貼的人 +2 |
  | 吐槽貼貼到一般瞎掰人 | 0 |
  | 這回合沒有人貼到暗樁 | 暗樁 +2 |
  | 裁判沒投（時間到或離線被跳過） | 投票這項沒有人得分，吐槽貼照算 |

- **看得到什麼（view 裁切）**：老實人看到名詞＋解釋；瞎掰人和暗樁看到名詞＋提示（選項可關）；暗樁另外看到自己的任務詞；裁判和旁觀者只看到名詞。每個人只知道自己的角色。揭曉時全部公開（老實人、暗樁、任務詞、解釋、裁判的票、每張吐槽貼）。
- **缺席**：裁判在準備時離線 → 房主跳過就開始朗讀；正在朗讀的人離線 → 跳到下一位；投票時沒決定的人離線 → 當作不貼；裁判投票時離線 → 他的票不算；揭曉時裁判離線 → 替他進下一回合。
- **聊天**：準備、朗讀、投票時關閉（打一句「我是老實人」就沒得玩了），揭曉時打開。朗讀本身面對面或開語音。
- **題庫**：只做繁中。名詞要真實存在、多數大學生不知道；解釋 60–120 字、用自己的話寫、不逐字搬百科、**不碰原作任何一題**。I1 的草稿由 AI 協作者寫，**擁有者要逐題審**（特別是事實正確）。
- I1 只有規則與題庫：`meta.unlisted`，要 `POST /api/rooms` `{"gameId":"bluff"}` 才開得了，畫面與規則頁在 I2。
- **I2（#45）**：手機優先畫面、揭曉、規則頁，**上大廳**（暫名；拿掉即將推出卡片）。e6-t06 等 F3 與 Q5。
