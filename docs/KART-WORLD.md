# KART-WORLD — 卡丁車的世界觀與命名（`e10-t01`）

> **草稿，待擁有者拍板。** 2026-11-17 起草（`feat/kart-roster-select`，和 N3 的 `e10-t05a` `e10-t05b` 同一個 PR）。這份只是**建議**：程式裡的名稱**都還是暫名**，這個 PR 沒有改任何現有暫名（避免和平行中的道具、觀戰、第三張賽道的 PR 衝突）。擁有者拍板後，另開一個小 PR 照 §6 改字串即可；**id 一律不改**（瀏覽器裡的紀錄、幽靈車、選車都用 id 存）。

## 1. 原則

- **全部原創**（CLAUDE.md 規則 1、`PRD/01-legal-ip-analysis.md` §4）：不用原作（KartRider／跑跑卡丁車）的任何角色、車名、外觀、道具名、賽道佈局。擁有者描述手感時提過的原作車名**一個都沒用、也沒有拿來改**。
- **在地、朋友圈的調性**：淡水河口、淡江、橋藝社。梗要讓社團朋友一看就懂，但不需要外人看懂。
- **名字短**：介面的選車按鈕、名牌、道具欄都窄；中文 2–4 字、英文 1–2 個字。
- **真實地名可以用**（淡水、漁人碼頭、五虎崗是地名，不是誰的商標）；**校徽、校名當商標用、真人不用**。淡江校園賽道只畫建築的風格化印象，現在路邊石頭上的純文字校名照舊。

## 2. 世界觀（建議）

**「河口盃懸浮車大賽」**（英文 *Rivermouth Cup*）：每年秋天，淡水河口的人會把自己改裝的懸浮車拿出來比一場。賽道沿著河岸、繞進漁港、爬上五虎崗的校園，再鑽進夜市的巷子。

今年報名的是**橋藝社的四個人**：社團的四張牌——黑桃、紅心、方塊、梅花——剛好湊一桌（橋牌四人一桌，梅花的英文 *club* 也剛好是「社團」）。他們開的車是自己照河口看得到的東西做的：渡輪、阿給、魟魚、招潮蟹、白鷺、飛魚。道具是河口的天氣與漁村的東西：順風、逆風、牽罟繩、泡泡……還有一招打牌的人都懂的「洗牌」。

- **基調**：輕鬆、自嘲、互虧，不是熱血戰鬥；輸了的人請宵夜。
- **沒有反派**：大家都是朋友；道具的說明文字用「惡作劇」的口吻，不用「攻擊」。
- **不做劇情模式**：世界觀只用在名稱、一句話介紹與賽道的布置。

### 4.1 數值（`shared/kart/karts.ts`）

每台車在「極速、加速、操控、甩尾集氣」四項各有 −2～+2 點，**四項加起來一定是 0**（測試擋）：強一項就要弱一項。重量另算（只影響車撞車）。一點的效果：

| 數值 | 一點 | 範圍 | 改的物理參數 |
| --- | --- | --- | --- |
| 極速 | 1% | ±2% | `topSpeed`（噴射的倍率都乘在它上面，所以一起變） |
| 加速 | 4% | ±8% | `acceleration` |
| 操控 | 4% | ±8% | `turnRate`、`driftTurnRate`、`driftSteerRate` |
| 甩尾集氣 | 5% | ±10% | `gaugeFillRate` |
| 重量 | 8% | ±16% | 車撞車時誰被推得多（`bumpKart`） |

| 車 | 極速 | 加速 | 操控 | 集氣 | 重量 | 極速 m/s |
| --- | --- | --- | --- | --- | --- | --- |
| `tide` | 0 | 0 | 0 | 0 | 0 | 60.0 |
| `comet` | −1 | +2 | +1 | −2 | −1 | 59.4 |
| `ray` | +1 | −1 | +1 | −1 | 0 | 60.6 |
| `crab` | 0 | −2 | +1 | +1 | +2 | 60.0 |
| `heron` | +2 | −1 | −2 | +1 | −1 | 61.2 |
| `flyfish` | −1 | 0 | −1 | +2 | 0 | 59.4 |

**為什麼極速差這麼小（最快 61.2、最慢 59.4，差 3%）**：這幾張賽道一圈大半是全速，極速每 1% 大約是高手一圈（26–34 秒）的 0.3 秒；3% 約一秒，比「乾淨的一圈」和「撞一次牆的一圈」的差距小很多，所以**還是開得好的人贏**，車只是風格。PRD 的上限是 ±5%，這裡刻意更小。加速、操控、集氣放寬到 ±8–10%，因為這些可以用技術補（起步加速、走線、多甩幾下）。`tide` 就是原本的標準數值，所以原本的手感完全沒變。

**紀錄與幽靈車**：計時賽的紀錄還是每張賽道一個，不分車（差距很小）。擁有者若覺得該分車，之後可以改成每台車各一個紀錄。
