# ROADMAP — 開發路線圖（2026-11-03 版）

這是從零到「M4 社群與打磨」的**全部順序**。一批 = 一個 PR = 一個 AI session。照批次號依序做，不跳批；每批做完在這裡把 `[ ]` 改成 `[x]` 並寫上 PR 號，同時更新 `docs/NEXT.md`「現在的位置」與 `docs/PRD/README.md` 進度表。task 的細節在 `docs/PRD/e*.md`，開工時只讀該批 task 所在的那一段。

Phase 用字母，**跳過 M**（避免和里程碑 M0…M4 混淆）。原本也跳過 E（避免和 Epic 編號 E1…E12 混淆）；擁有者 2026-11-09 要求的介面方向用了 **Phase E**，所以文件裡提到這一批要寫「批次 E1」，和「Epic E1（大廳、身分與房間）」分開。

**完成的定義**：
- 做完 **Phase A–D** ＝ **M0 能開桌**：大廳、暱稱、房間、GameModule、RoomDO、重連、陞官圖、聊天、雙語、部署。4 個朋友各自的裝置玩完一局陞官圖就算。
- 做完 **Phase F–I** ＝ **M1 派對桌遊三款**：帳號、戰績、默契牌局、光譜猜題、真假朗讀、題庫工具、PWA、視覺回歸。一次聚會玩完三款。
- 做完 **Phase J–K** ＝ **M2 卡丁車單機**：手感、賽道、時間賽、幽靈、手把、音效。擁有者簽核「手感 OK」。
- 做完 **Phase L、N** ＝ **M3 卡丁車多人**：同步、道具賽、競速房、觀戰、賽道 2–3、角色與車款。6 人同房跑完一場。
- 做完 **Phase O–P** ＝ **M4**：好友、成就、排行、投票、功能旗標、成本儀表板、賽道編輯器。

開工指令（貼給 Claude，建議 Opus、effort medium）：

```
讀 CLAUDE.md、docs/NEXT.md、docs/ROADMAP.md。做 ROADMAP 第 <批次號> 批，照 NEXT.md 第 3 點的規則：
worktree 開分支、只讀需要的段落、lint+typecheck+test+build 只看最後 5 行、一批一個 ready PR（標題列出全部 task 編號、本文寫 AC 與檢查）、
在 PRD 勾選並更新進度表、在 ROADMAP 勾選這一批並寫 PR 號、更新 NEXT.md「現在的位置」，CI 綠了直接合併（需要人決定的事才停），合併後回報並結束。
介面文字一律走 i18n（en 來源、zh-TW 翻譯），新資產一律登記 docs/ASSETS.md；卡丁車多人的 AC 要在兩台裝置實測才能勾。
```
