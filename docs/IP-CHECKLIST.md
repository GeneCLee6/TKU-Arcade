# IP 檢查清單

每款遊戲上線前跑一次（AC-12.8）。原則與理由見 [`PRD/01-legal-ip-analysis.md`](PRD/01-legal-ip-analysis.md) §4：**玩法可學，表達不抄。** 這份不是法律意見；真的被通知或想對外發布前，找律師。

## 怎麼用

1. 上線前，在下面「簽核紀錄」複製一份範本，填遊戲名稱與 commit。
2. 每一行寫**實際查了什麼**，不寫「應該沒問題」。查不了的（要人判斷的）就留給擁有者。
3. 全部是「通過」或經擁有者同意的「不適用」之後，**擁有者本人**簽名與寫日期。AI 協作者可以填查核結果，不能代簽。
4. 有「待補」或「未通過」就不算簽核完成，也不對朋友以外的人提這款遊戲。

#### 給擁有者

1. **`README.md` 寫了原作名稱**：遊戲表的「Mechanics inspired by」欄有 *The Gang*、*Wavelength*、*9upper*。這是描述性使用（§1.2 認為通常沒問題），但 §4-2 與 `CLAUDE.md` 硬性規則 1 寫的是「只在規則頁用一句話」。兩邊不一致，要嘛改規則文字，要嘛改 README；這與升官圖無關，不擋這次簽核，但 M1 三款上線前要定案。
2. **`README.md` 說資產「registered in `docs/ASSETS.md`」，這個檔案還不存在**（`e12-t08`）。目前沒有資產檔，所以不是違規，只是句子走在實作前面。
3. 第 2、3 行的「沒有照抄出版社版本」只能由知道這份資料怎麼來的人確認；查核只能看到 repo 裡的東西。
